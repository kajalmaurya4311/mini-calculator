#  Python CLI Calculator

A simple, fast, and interactive Command-Line Interface (CLI) Calculator built in pure Python. It takes two numbers from the user and performs basic arithmetic operations based on the user's input.

##  Features
- **Basic Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Modern Python Syntax:** Utilizes the clean `match-case` statement introduced in Python 3.10 for efficient logic handling.
- **Error Handling:** Built-in `try-except` block prevents the program from crashing if the user enters non-integer values (like letters or symbols).
- **Lightweight:** Runs directly in the terminal with zero external dependencies.

##  Prerequisites
Because this script uses the `match-case` statement, you must have **Python 3.10 or higher** installed on your system.
